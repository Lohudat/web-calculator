# Web Calculator

A simple, clean, and functional calculator web application for basic arithmetic operations.

## Features

- ✅ Basic operations: Addition, Subtraction, Multiplication, Division
- ✅ Decimal number support
- ✅ Sign toggle (+/−)
- ✅ Clear functionality
- ✅ Responsive and modern UI

## Demo

🔗 **[Live Demo](https://lohudat.github.io/web-calculator/)**

## How to Use

1. Click on number buttons (0-9) to enter numbers
2. Click on operation buttons (+, −, ×, /) to select an operation
3. Click the equals button (=) to calculate the result
4. Click the C button to clear the display

## Files

- `index.html` - Calculator HTML structure
- `style.css` - Calculator styling and layout
- `script.js` - Calculator logic and functionality

## Getting Started

Simply open `index.html` in your web browser to start using the calculator.
